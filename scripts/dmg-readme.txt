Dropwheel — конвертер файлов колесом (macOS 14+, Apple Silicon и Intel).

1. Перетащите Dropwheel в папку «Программы» (Applications) и запустите.
2. Иконка появится в строке меню. Перетаскивайте файл и зажмите Shift —
   появится колесо форматов.
3. Обновления приходят сами: раз в день приложение проверяет новую версию
   и ставит её, когда не занято конвертацией.

Аудио и видео: нужен ffmpeg (brew install ffmpeg). WebP: brew install webp.
Картинки, PDF и документы работают без них.
